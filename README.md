# Ronaldo.exe Studio 1.4 Build

A studio 1.4 build of ronaldo.exe for older devices

This include builds for the Psvita, PS4, PS3, and PS2 

Main repository  https://github.com/ooodt/ronaldo.exe?tab=readme-ov-file

### Tools used

Psvita: [GayMaker](https://github.com/LiEnby/GayMaker)

PS4: [GayMaker-Studio](https://github.com/LiEnby/GayMaker-Studio)

PS3: [GayMaker-PS3](https://github.com/LiEnby/GayMaker-PS3)

PS2: [Butterscotch PS2](https://butterscotch.mrpowergamerbr.com/)
